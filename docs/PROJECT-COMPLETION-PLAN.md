## How to split a session among agents

Use one lead and up to three workers when available and authorized. With a single agent, execute the same assignments sequentially. The lead owns integration, shared decisions, checklist edits and the persistent manual fixture. Give each worker a checklist ID, base revision, allowed paths, expected behavior, tests and a return format. Agents here share the checkout. Use disjoint paths or separate Git worktrees for parallel edits. Assign a single writer for each shared schema, migration manifest, contract index, lockfile or route. Sequence dependent changes from the same agreed contract.
